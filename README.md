# سیستم مدیریت و نظارت بر ادمین اینستاگرام 📊

سیستم جامع برای مدیریت، پیگیری و نظارت بر عملکرد ادمین‌های اینستاگرام با امکانات پیشرفته

## ✨ ویژگی‌ها

### 🎯 برای ادمین اینستاگرام:
- ✅ چک‌لیست وظایف روزانه با 15+ وظیفه پیش‌فرض
- 📊 ثبت آمار روزانه (فالوور، فالووینگ، ایمپرشن، بازدید پروفایل)
- 📈 نمودارهای تحلیلی رشد 7 روز اخیر
- 🎁 سیستم جوایز و چالش‌های انگیزشی (100، 250، 500، 1K، 2.5K، 5K، 10K فالوور)
- 💪 پیام‌های انگیزشی هوشمند بر اساس زمان روز
- 🕐 محاسبه زمان صرف شده برای هر وظیفه
- 📅 تاریخ شمسی (جلالی) کامل
- ⚡ انیمیشن‌های زیبا و نرم
- 📱 طراحی موبایل‌محور و ریسپانسیو

### 👔 برای مدیر:
- 👥 نظارت بر عملکرد تمام ادمین‌ها
- 📊 مشاهده آمار کلی و جزئی
- 📋 گزارش میزان تکمیل وظایف هر ادمین
- 🕒 لاگ تمام فعالیت‌ها
- 🏆 پیگیری دستیابی به اهداف
- 📈 نمودارهای مقایسه‌ای

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها:
- PHP 8.0 یا بالاتر
- MySQL 8.0 یا بالاتر
- وب‌سرور Apache یا Nginx
- PDO PHP Extension

### مراحل نصب:

#### 1. آپلود فایل‌ها
تمام فایل‌های پروژه را در پوشه root وب‌سایت خود قرار دهید.

#### 2. ایجاد پایگاه داده
دستورات SQL موجود در فایل `database.sql` را اجرا کنید:

```bash
mysql -u root -p < database.sql
```

یا از phpMyAdmin:
1. پایگاه داده `instagram_admin` را ایجاد کنید
2. محتویات فایل `database.sql` را در آن اجرا کنید

#### 3. تنظیمات اتصال به دیتابیس
فایل `db.php` را باز کنید و اطلاعات دیتابیس خود را وارد کنید:

```php
define('DB_HOST', 'localhost');     // آدرس سرور دیتابیس
define('DB_NAME', 'instagram_admin'); // نام دیتابیس
define('DB_USER', 'root');           // نام کاربری دیتابیس
define('DB_PASS', '');               // رمز عبور دیتابیس
```

#### 4. تنظیم دسترسی‌ها
مطمئن شوید پوشه پروژه دسترسی خواندن و نوشتن دارد:

```bash
chmod -R 755 /path/to/project
```

#### 5. دسترسی به سیستم
سیستم آماده استفاده است! به آدرس وب‌سایت خود بروید.

## 🐛 رفع مشکلات رایج

### مشکل: صفحه سفید نمایش داده می‌شود
- خطاهای PHP را فعال کنید:
  ```php
  ini_set('display_errors', 1);
  error_reporting(E_ALL);
  ```
- دسترسی فایل‌ها را بررسی کنید

### مشکل: نمی‌توان به دیتابیس متصل شد
- اطلاعات دیتابیس در `db.php` را بررسی کنید
- مطمئن شوید MySQL در حال اجرا است
- دسترسی کاربر دیتابیس را بررسی کنید

### مشکل: تاریخ فارسی نمایش داده نمی‌شود
- تنظیمات زمان سرور را بررسی کنید
- Timezone PHP را تنظیم کنید:
  ```php
  date_default_timezone_set('Asia/Tehran');
  ```

### مشکل: نمودارها نمایش داده نمی‌شوند
- اتصال اینترنت را بررسی کنید (Chart.js از CDN لود می‌شود)
- یا Chart.js را به صورت محلی دانلود کنید
