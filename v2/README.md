# سیستم مدیریت اینستاگرام - نسخه 2.0

## 🎯 ویژگی‌ها

### ✨ طراحی Wizard (مرحله به مرحله)
- **7 مرحله گزارش‌گیری** با نمایش پیشرفت
- **Progress Bar حرفه‌ای** برای نمایش وضعیت
- **فرم‌های بهینه شده** با Counter های تعاملی
- **پیش‌نمایش امتیاز** در مرحله خلاصه

### 📊 سیستم امتیازدهی هوشمند
- محاسبه امتیاز بر اساس **15 معیار مختلف**
- نمایش امتیاز با **رنگ‌بندی دقیق**:
  - 90-100: عالی (سبز)
  - 75-89: خوب (آبی)
  - 60-74: متوسط (نارنجی)
  - 0-59: نیاز به بهبود (قرمز)

### 📱 گزارش قابل اسکرین‌شات
- **تک‌صفحه‌ای** برای راحتی اسکرین‌شات
- **طراحی مدرن** و حرفه‌ای
- **نمودار دایره‌ای امتیاز**
- **جزئیات کامل** تمام تسک‌ها
- **قابل چاپ** با استایل‌های مخصوص

### 📈 داشبورد مدیریت پیشرفته
- **نمودار روند عملکرد** 30 روز اخیر (Line Chart)
- **نمودار توزیع امتیاز** بر اساس دسته (Doughnut Chart)
- **کارت‌های آماری** جذاب و تعاملی
- **جدول گزارش‌ها** با فیلتر و صفحه‌بندی

## 🚀 نصب و راه‌اندازی

### 1. آپلود فایل‌ها
تمام فایل‌ها را در پوشه مورد نظر آپلود کنید.

### 2. ایجاد دیتابیس
```sql
1. یک دیتابیس جدید ایجاد کنید
2. فایل database.sql را import کنید
```

### 3. تنظیم اتصال دیتابیس
فایل `db.php` را ویرایش کنید:

```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'your_database_name');
define('DB_USER', 'your_username');
define('DB_PASS', 'your_password');
```

### 4. تنظیم مجوزها
```bash
chmod 644 *.php
chmod 755 .
```

### 5. ورود به سیستم
```
URL: http://your-domain.com/
رمز ادمین: admin123
رمز مدیریت: manager123
```
