   راهنمای نصب سیستم مدیریت اینستاگرام - نسخه 2.0
═══════════════════════════════════════════════════════════

🚀 مراحل نصب سریع:

┌─────────────────────────────────────────────────────────┐
│ مرحله 1: آپلود فایل‌ها                                 │
└─────────────────────────────────────────────────────────┘

1. فایل instagram-manager-v2.zip را از هاست خود استخراج کنید
2. تمام محتویات پوشه v2 را در مسیر دلخواه آپلود کنید
   (مثلاً: public_html/instagram/ یا public_html/)

┌─────────────────────────────────────────────────────────┐
│ مرحله 2: ایجاد دیتابیس                                 │
└─────────────────────────────────────────────────────────┘

1. وارد cPanel شوید
2. به MySQL Databases بروید
3. یک دیتابیس جدید بسازید (مثلاً: instagram_db)
4. یک کاربر جدید بسازید و رمز تنظیم کنید
5. کاربر را به دیتابیس اضافه کنید (با تمام دسترسی‌ها)

┌─────────────────────────────────────────────────────────┐
│ مرحله 3: Import دیتابیس                                │
└─────────────────────────────────────────────────────────┘

1. به phpMyAdmin بروید
2. دیتابیس ایجاد شده را انتخاب کنید
3. روی تب "Import" کلیک کنید
4. فایل database.sql را انتخاب و آپلود کنید
5. روی "Go" کلیک کنید

┌─────────────────────────────────────────────────────────┐
│ مرحله 4: تنظیم اتصال دیتابیس                           │
└─────────────────────────────────────────────────────────┘

فایل db.php را ویرایش کنید و اطلاعات زیر را وارد کنید:

define('DB_HOST', 'localhost');           // معمولاً localhost
define('DB_NAME', 'instagram_db');         // نام دیتابیس شما
define('DB_USER', 'instagram_user');       // نام کاربری دیتابیس
define('DB_PASS', 'your_password');        // رمز عبور دیتابیس

💡 نکته: این اطلاعات را از cPanel خود دریافت کنید

┌─────────────────────────────────────────────────────────┐
│ مرحله 5: ورود به سیستم                                 │
└─────────────────────────────────────────────────────────┘

1. به آدرس سایت خود بروید:
   http://your-domain.com/instagram/

2. اطلاعات ورود پیش‌فرض:

   📱 ادمین اینستاگرام:
   • نقش: admin
   • رمز عبور: admin123

   👤 مدیریت:
   • نقش: manager
   • رمز عبور: manager123

3. ⚠️ مهم: حتماً رمزهای عبور را تغییر دهید!

┌─────────────────────────────────────────────────────────┐
│ تغییر رمز عبور                                          │
└─────────────────────────────────────────────────────────┘

برای تغییر رمز عبور:

1. به phpMyAdmin بروید
2. جدول "users" را باز کنید
3. رمز جدید را با این کد PHP هش کنید:

   <?php echo password_hash('رمز_جدید_شما', PASSWORD_DEFAULT); ?>

4. مقدار hash شده را در فیلد password کپی کنید

⚙️ تنظیمات اختیاری:

🔒 افزایش امنیت:
- فایل database.sql را حذف کنید (بعد از import)
- دسترسی‌های فایل‌ها را بررسی کنید (chmod 644)

⚡ بهینه‌سازی عملکرد:
- فعال‌سازی caching در هاست
- فعال‌سازی Gzip compression
- استفاده از CDN برای فونت‌ها
