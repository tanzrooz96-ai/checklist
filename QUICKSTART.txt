⚠️ مرحله 7: تغییر رمزهای پیش‌فرض (مهم!)
----------------------------------

برای امنیت، حتماً رمزها را تغییر دهید:

🔹 تغییر رمز ورود:

1. به phpMyAdmin بروید
2. جدول users را باز کنید
3. روی Edit کلیک کنید
4. در فیلد password از Function انتخاب کنید: MD5
5. رمز جدید را وارد کنید
6. ذخیره کنید

   یا از این کد PHP استفاده کنید:

   <?php
   echo password_hash('رمز_جدید_شما', PASSWORD_DEFAULT);
   ?>

🔹 تغییر رمز ویرایش گزارش:

1. فایل api.php را ویرایش کنید - خط 445:
   $correctPassword = 'رمز_جدید';

2. فایل report.php را ویرایش کنید - خط 711:
   const correctPassword = 'رمز_جدید';

===============================================
🐛 رفع مشکلات رایج
----------------------------------

❌ صفحه سفید (White Screen):

1. خطاها را نمایش دهید:
   در db.php بالای فایل اضافه کنید:
   error_reporting(E_ALL);
   ini_set('display_errors', 1);

2. بررسی کنید:
   - نسخه PHP حداقل 8.0 است؟
   - فایل db.php اطلاعات صحیح دارد؟
   - دیتابیس درست import شده؟

❌ خطای اتصال به دیتابیس:

1. اطلاعات db.php را دوباره بررسی کنید
2. مطمئن شوید کاربر MySQL دسترسی دارد
3. دیتابیس با نام درست ساخته شده است

❌ تاریخ نمایش داده نمی‌شود:

1. این خطا برطرف شده است!
2. اگر باز دیدید، فایل db.php را دوباره آپلود کنید

❌ مودال باز نمی‌شود:

1. Console مرورگر را بررسی کنید (F12)
2. مطمئن شوید script.js لود شده است
3. کش مرورگر را پاک کنید (Ctrl + F5)

❌ استایل‌ها اعمال نمی‌شود:

1. مطمئن شوید style.css آپلود شده است
2. کش مرورگر را پاک کنید
3. .htaccess را بررسی کنید
