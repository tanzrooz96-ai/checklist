================================================================
راهنمای نصب سیستم مدیریت ادمین اینستاگرام
================================================================

این فایل راهنمای گام‌به‌گام نصب سیستم را ارائه می‌دهد.

================================================================
1. پیش‌نیازها
================================================================

قبل از شروع نصب، مطمئن شوید موارد زیر را دارید:

✓ سرور با PHP نسخه 8.0 یا بالاتر
✓ MySQL نسخه 8.0 یا بالاتر
✓ وب‌سرور Apache یا Nginx
✓ دسترسی به cPanel یا SSH
✓ حداقل 50MB فضای دیسک

================================================================
2. دانلود و آپلود فایل‌ها
================================================================

مرحله 1: تمام فایل‌های زیر را در پوشه root وب‌سایت (public_html) قرار دهید:

- index.php
- admin.php
- manager.php
- logout.php
- api.php
- db.php
- style.css
- script.js
- database.sql
- .htaccess
- README.md

================================================================
3. ایجاد پایگاه داده
================================================================

روش اول - استفاده از cPanel:

1. وارد cPanel شوید
2. روی "MySQL Databases" کلیک کنید
3. یک دیتابیس جدید با نام "instagram_admin" بسازید
4. یک کاربر MySQL جدید بسازید
5. کاربر را به دیتابیس متصل کنید و تمام دسترسی‌ها را بدهید
6. وارد phpMyAdmin شوید
7. دیتابیس instagram_admin را انتخاب کنید
8. روی تب "SQL" کلیک کنید
9. محتویات فایل database.sql را کپی و در کادر SQL پیست کنید
10. روی "Go" یا "اجرا" کلیک کنید

روش دوم - استفاده از SSH:

mysql -u USERNAME -p
CREATE DATABASE instagram_admin CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
exit

mysql -u USERNAME -p instagram_admin < database.sql

================================================================
4. پیکربندی اتصال به دیتابیس
================================================================

1. فایل db.php را باز کنید
2. خطوط زیر را پیدا کنید:

define('DB_HOST', 'localhost');
define('DB_NAME', 'instagram_admin');
define('DB_USER', 'root');
define('DB_PASS', '');

3. مقادیر را با اطلاعات دیتابیس خود جایگزین کنید:

DB_HOST → معمولاً localhost است
DB_NAME → نام دیتابیسی که ساختید
DB_USER → نام کاربری MySQL
DB_PASS → رمز عبور MySQL

4. فایل را ذخیره کنید

================================================================
5. تنظیم دسترسی فایل‌ها
================================================================

اگر از SSH استفاده می‌کنید:

chmod 644 *.php
chmod 644 *.css
chmod 644 *.js
chmod 644 .htaccess
chmod 755 /path/to/directory

================================================================
6. تست سیستم
================================================================

1. مرورگر خود را باز کنید
2. به آدرس وب‌سایت خود بروید
3. باید صفحه ورود را ببینید

اگر صفحه سفید دیدید:
- فایل db.php را بررسی کنید
- خطاهای PHP را فعال کنید
- لاگ‌های خطا را بررسی کنید

================================================================
7. ورود به سیستم
================================================================

برای ادمین اینستاگرام:
- نوع کاربری: انتخاب "ادمین اینستاگرام"
- رمز عبور: admin123

برای مدیر:
- نوع کاربری: انتخاب "مدیریت"
- رمز عبور: manager123

================================================================
8. تغییر رمز عبور (مهم!)
================================================================

بعد از اولین ورود، حتماً رمز عبور را تغییر دهید:

از طریق SQL:

UPDATE users
SET password = '$2y$10$NEW_HASHED_PASSWORD'
WHERE username = 'admin';

برای ساخت رمز عبور جدید از این کد PHP استفاده کنید:

<?php
echo password_hash('رمز_جدید', PASSWORD_DEFAULT);
?>

9. تنظیمات اختیاری
================================================================

✓ فعال‌سازی HTTPS:
  در فایل .htaccess خطوط مربوط به Force HTTPS را فعال کنید

✓ تنظیم منطقه زمانی:
  در فایل db.php اضافه کنید:
  date_default_timezone_set('Asia/Tehran');

✓ افزایش امنیت:
  - فایل .htaccess را بررسی و تنظیم کنید
  - تمام رمزهای پیش‌فرض را تغییر دهید
  - دسترسی‌های فایل را محدود کنید
